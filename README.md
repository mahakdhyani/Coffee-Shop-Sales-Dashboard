# Coffee-Shop-Sales-Dashboard

An interactive Coffee Shop Sales Dashboard built using Microsoft Power BI
to analyze sales performance, customer ordering patterns, product performance, store-level sales, and order trends. The dashboard provides a consolidated view of key business KPIs and interactive visualizations that help identify sales trends and understand customer purchasing behavior. 

## Dataset Used
https://mavenanalytics.io/data-playground/coffee-shop-sales

## 🎯 Project Objective

The main objective of this project is to transform coffee shop sales data into an interactive and easy-to-understand business intelligence dashboard.

The dashboard helps analyze:

- Overall sales performance
- Total number of orders
- Average bill per person
- Average order quantity per person
- Sales by product category
- Sales distribution by product size
- Top-performing products
- Store/location-wise sales
- Order trends by day of the week
- Hourly order patterns
